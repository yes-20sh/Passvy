### Rules

Use kebab-case for folders → user-profile/
Use PascalCase for components → UserCard.tsx
Use camelCase for hooks/utils → useAuth.ts, formatDate.ts
Use lowercase route names → app/dashboard/
Use route groups with () → (auth)/
Use dynamic routes with [] → [id]/
Use aliases @/ instead of relative imports
SCSS globals → globals.scss
SCSS modules → Button.module.scss
Constants → UPPER_SNAKE_CASE
